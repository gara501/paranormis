# Studio de Paranormis

Este Studio usa el proyecto Sanity `en0s05um` y el dataset `production`. Sus esquemas mantienen los mismos nombres de tipos, campos y valores que Apex Bestiary; las etiquetas del editor están en español.

Desde esta carpeta, instala las dependencias e inicia el entorno local:

```bash
npm install
npm run dev
```

Para publicar el Studio:

```bash
npm run deploy
```

En el primer despliegue, Sanity pedirá elegir un hostname disponible para el Studio. La publicación requiere una cuenta autorizada en el proyecto Sanity.
